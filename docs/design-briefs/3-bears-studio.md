- Radii: buttons `999px`, cards `18px`, chips `999px`

- Secondary button: transparent, `rgba(207,234,245,.38)` border
- Shadow: `0 1px 2px rgba(16,32,52,.05), 0 8px 24px rgba(16,32,52,.06)`

## Rules — not negotiable

- Fraunces is SELF-HOSTED from the repo. Never load a font from a CDN — the site makes zero third-party requests and that is an invariant.
- Use the TRUE italic, never a synthesized slant; a faux oblique looks wrong on a display serif.
- A film-grain layer sits over the whole page at low opacity.
- Everything must survive JS being off, honour prefers-reduced-motion, and never scroll horizontally between 360px and 1440px.

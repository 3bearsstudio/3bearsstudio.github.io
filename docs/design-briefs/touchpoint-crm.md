- Radii: cards `16px`, small `10px`
- Primary button: `#1565C0` ground, `#ffffff` label

## Rules — not negotiable

- The ONLY system here that ships a real light mode and a real dark mode. Design both; do not assume dark.
- iPhone AND Android — the Kotlin codebase is real (~26.5k lines). Layouts should survive both platforms' conventions.

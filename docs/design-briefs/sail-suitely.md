## Surfaces

- Page ground `#0A1730`, text `#F5F1E8`, muted `rgba(245,241,232,.68)`, hairline `rgba(209,173,102,.22)`
- Radii: buttons `4px`, cards `8px`, device frame `46px`
- Primary button: `#D1AD66` ground, `#0A1730` label
- Secondary button: transparent, `rgba(209,173,102,.42)` border
- Shadow: `0 26px 55px rgba(0,0,0,.55)`

## Rules — not negotiable

- Restraint is the brand. Gold is an accent on deep navy — never a fill, never a gradient wash. If it looks like a casino, it is wrong.
- Tight corner radii (4–8px) read as considered; big soft rounding reads as consumer app and fights the positioning.
- Co-created with Monica (contractor, not an owner).
